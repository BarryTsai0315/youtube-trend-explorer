## 🚀 第一步：申請 YouTube API Key

### 為什麼需要 API Key？

API Key 就像是您進入 YouTube 數據庫的「鑰匙」。Google 免費提供每天 10,000 次查詢額度，足夠個人使用。

### 申請步驟 (約 10 分鐘)

#### 1. 建立 Google Cloud 專案

1. 開啟 [Google Cloud Console](https://console.cloud.google.com/)
2. 點擊右上角「登入」，使用您的 Google 帳號
3. 點擊頁面上方的「選取專案」
4. 點擊「新增專案」
5. 輸入專案名稱，例如：「YouTube搜尋器」
6. 點擊「建立」

#### 2. 啟用 YouTube Data API

1. 在左側選單找到「API 和服務」→「程式庫」
2. 搜尋「YouTube Data API v3」
3. 點擊進入，然後點擊「啟用」

#### 3. 建立 API 金鑰

1. 左側選單點擊「API 和服務」→「憑證」
2. 點擊頁面上方「+ 建立憑證」
3. 選擇「API 金鑰」
4. 複製產生的 API 金鑰並妥善保存

#### 4. 設定安全限制 (重要！)

1. 點擊剛建立的 API 金鑰
2. 在「應用程式限制」中選擇「HTTP 參照網址」
3. 新增您要使用的網址，例如：
   - `https://yourusername.github.io/*` (如果使用 GitHub Pages)
   - `http://localhost:*` (如果本地測試)
4. 點擊「儲存」

## 🛠️ 第二步：設定工具

### 方式 A：使用 GitHub Pages (推薦新手)

1. 前往 [專案頁面](https://github.com/BarryTsai0315/youtube-trend-explorer)
2. 點擊右上角「Fork」按鈕
3. 在您的 repository 中，點擊「Settings」
4. 左側選單找到「Pages」
5. 在「Source」中選擇「Deploy from a branch」
6. 選擇「main」分支，點擊「Save」
7. 幾分鐘後，您會得到一個類似 `https://yourusername.github.io/youtube-trend-explorer` 的網址

### 方式 B：下載到電腦

1. 點擊專案頁面的綠色「Code」按鈕
2. 選擇「Download ZIP」
3. 解壓縮檔案到您想要的位置
4. 雙擊 `index.html` 檔案開啟

## 🔑 第三步：輸入您的 API Key

1. 開啟 `index.html` 頁面
2. 在「YouTube API Key」欄位輸入您的 API 金鑰
3. 點擊「驗證並儲存」
4. 看到綠色「✓ API Key 驗證成功」即表示設定完成

**安全提醒**: API Key 只會儲存在您的瀏覽器中，不會傳送到任何伺服器。

## 📖 使用教學

### 🔍 基本搜尋功能

#### 進入搜尋器

- 點擊首頁的「開始搜尋影片」按鈕
- 或直接開啟 `youtube-search-frontend.html`

#### 設定搜尋條件

1. **關鍵字**: 輸入您想搜尋的主題，例如「料理教學」
2. **地區**: 選擇目標地區 (台灣、美國、日本等)
3. **影片類型**:
   - 一般影片：傳統長影片
   - Shorts：短影片 (60秒以內)
4. **進階篩選**:
   - 發布日期：最近一天/一週/一個月/一年
   - 觀看數範圍：設定最小和最大觀看數

#### 檢視搜尋結果

點擊「搜尋」後，您會看到：

- **影片縮圖**: 點擊可直接觀看
- **標題和頻道**: 影片基本資訊
- **統計數據**: 觀看數、按讚數、留言數
- **發布時間**: 影片上傳日期

### 📊 數據分析功能

#### 切換到圖表檢視

點擊「圖表分析」按鈕，您可以看到：

1. **觀看數分布圖**: 了解影片觀看數的分布情況
2. **發布時間趨勢**: 看出什麼時候發布的影片比較多
3. **影片類型分布**: 一般影片 vs Shorts 的比例
4. **按讚率散點圖**: 觀看數與按讚率的關係

#### 數據洞察

圖表下方會顯示自動分析的重點，例如：

- 平均觀看數
- 最熱門的發布時段
- 按讚率趨勢

### 📁 匯出數據

如果您需要進一步分析數據：

1. 點擊「匯出 CSV」按鈕
2. 選擇儲存位置
3. 檔案包含所有影片的詳細資訊
4. 可用 Excel 或 Google Sheets 開啟

### 🔍 競品比較功能

#### 進入競品比較工具

- 點擊首頁的「競品比較分析」
- 或直接開啟 `compare.html`

#### 比較多個關鍵字

1. 在搜尋框輸入多個關鍵字，用逗號分隔
   - 例如：「iPhone 15, Samsung S24, Google Pixel 8」
2. 點擊「開始比較」
3. 系統會並排顯示各關鍵字的搜尋結果
4. 可以直接對比不同主題的熱門程度

## 💡 使用技巧

### 🔄 定期監控

- **建立關鍵字清單**: 定期搜尋相同關鍵字
- **追蹤競爭對手**: 監控特定頻道的表現

## ⚠️ 常見問題

### Q: API Key 配額用完了怎麼辦？

**A**: 每日配額會在美國太平洋時間午夜重置。您也可以申請配額增加，或建立多個專案。

### Q: 搜尋結果為什麼和 YouTube 不一樣？

**A**: 我們使用 YouTube Data API，結果可能與網頁版略有差異。這是正常現象。

### Q: 可以搜尋其他語言的影片嗎？

**A**: 可以！選擇對應的地區，並使用該語言的關鍵字搜尋。

### Q: 數據多久更新一次？

**A**: YouTube API 數據通常有幾分鐘到幾小時的延遲，這是正常的。

### Q: 可以搜尋私人或未列出的影片嗎？

**A**: 不可以，只能搜尋公開的影片。

### Q: 如何提高搜尋準確度？

**A**:

- 使用具體的關鍵字
- 適當設定篩選條件
- 選擇正確的地區設定

## 🔧 故障排除

### 問題：API Key 驗證失敗

**解決方式**:

1. 確認 API Key 複製完整，沒有多餘空格
2. 檢查是否已啟用 YouTube Data API v3
3. 確認 API Key 限制設定正確

### 問題：搜尋沒有結果

**解決方式**:

1. 嘗試更簡單的關鍵字
2. 檢查地區設定是否正確
3. 放寬篩選條件 (日期、觀看數範圍)

### 問題：圖表顯示異常

**解決方式**:

1. 重新整理頁面
2. 確認瀏覽器支援 JavaScript
3. 清除瀏覽器快取

### 問題：CSV 匯出失敗

**解決方式**:

1. 確認瀏覽器允許下載檔案
2. 檢查磁碟空間是否足夠
3. 嘗試匯出較少筆數的資料
