## API 端點直接測試

### 搜尋 API 測試
```bash
# 基本搜尋
curl "YOUR_API_URL?q=music&regionCode=TW&max=10"

# 預期回應格式
{
  "query": "music",
  "regionCode": "TW",
  "count": 10,
  "items": [...]
}
```

### 篩選 API 測試
```bash
# 進階篩選
curl "YOUR_API_URL?action=filter&region=TW&type=videos&viewMin=1000&page=1&size=20"

# 預期回應格式
{
  "total": 150,
  "page": 1,
  "size": 20,
  "totalPages": 8,
  "items": [...],
  "filters": {...}
}
```

### 建議 API 測試
```bash
# 搜尋建議
curl "YOUR_API_URL?action=suggestions&type=keyword"

# 預期回應格式
{
  "suggestions": [
    {
      "text": "AI 教學",
      "type": "keyword",
      "count": 150
    }
  ]
}
```

## 故障排除

### 常見問題及解決方案

1. **API 連線失敗**
   - 檢查 Apps Script 部署狀態
   - 驗證 API URL 正確性
   - 確認網路連線正常

2. **搜尋無結果**
   - 檢查 YouTube API 配額
   - 驗證搜尋條件是否過於嚴格
   - 確認 API 金鑰有效性

3. **頁面載入緩慢**
   - 檢查網路速度
   - 驗證 Apps Script 執行效能
   - 確認快取機制運作正常

4. **行動裝置顯示問題**
   - 檢查 CSS 響應式設計
   - 驗證觸控操作功能
   - 確認字體大小適當
