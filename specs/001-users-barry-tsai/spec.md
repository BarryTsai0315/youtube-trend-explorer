## 使用者場景與測試 *(必要)*

### 主要使用者故事
使用者希望能夠搜尋 YouTube 熱門影片，透過多種條件進行篩選（如關鍵字、地區、影片類型等），並以視覺化的卡片格式查看搜尋結果，包含影片縮圖、統計數據和相關資訊。

### 驗收場景
1. **假設** 使用者開啟搜尋頁面，**當** 輸入關鍵字並選擇地區，**則** 系統顯示符合條件的熱門影片列表
2. **假設** 使用者設定觀看數範圍篩選條件，**當** 執行搜尋，**則** 僅顯示觀看數在指定範圍內的影片
3. **假設** 使用者選擇顯示前 N 名影片，**當** 搜尋完成，**則** 結果限制在指定數量內並按熱門程度排序
4. **假設** 搜尋結果顯示，**當** 使用者點擊影片卡片，**則** 開啟對應的 YouTube 影片頁面
5. **假設** 大量搜尋結果，**當** 使用分頁功能，**則** 結果分頁顯示並提供頁面導航

### 邊界情況
- 搜尋無結果時如何顯示友善提示？
- 網路連線失敗時如何處理錯誤？
- 篩選條件衝突時如何處理？
- API 限制觸及時如何回應使用者？

## 需求 *(必要)*

### 功能需求
- **FR-001**: 系統必須提供關鍵字搜尋功能，允許使用者輸入任意文字進行影片搜尋
- **FR-002**: 系統必須支援地區篩選，提供多個國家/地區選項供使用者選擇
- **FR-003**: 系統必須允許使用者設定顯示結果數量上限（前 N 名）
- **FR-004**: 系統必須提供日期範圍篩選功能，讓使用者選擇特定時間段的影片
- **FR-005**: 系統必須支援觀看數範圍篩選，包含最小值和最大值設定
- **FR-006**: 系統必須支援影片類型篩選（一般影片 vs Shorts 短影片）
- **FR-007**: 系統必須以卡片格式顯示搜尋結果，每張卡片包含：
  - YouTube 影片縮圖
  - 影片標題
  - 頻道名稱
  - 地區資訊
  - 觀看數
  - 按讚數
  - 留言數
  - Hashtag 標籤
  - 影片長度
- **FR-008**: 系統必須提供分頁功能，當結果數量龐大時分頁顯示
- **FR-009**: 系統必須支援即時搜尋，在使用者修改篩選條件時自動更新結果
- **FR-010**: 系統必須提供結果統計資訊，顯示找到的總影片數量
- **FR-011**: 系統必須允許使用者點擊影片卡片直接跳轉到 YouTube 觀看
- **FR-012**: 系統必須提供重新整理功能，讓使用者手動更新資料

### 關鍵實體 *(涉及資料時才包含)*
- **影片實體**: 代表 YouTube 影片，包含 ID、標題、頻道、發布時間、統計數據、縮圖連結、hashtag 等資訊
- **搜尋篩選器**: 代表搜尋條件，包含關鍵字、地區、日期範圍、觀看數範圍、影片類型等篩選參數
- **搜尋結果**: 代表搜尋結果集合，包含符合條件的影片列表、總數量、分頁資訊等
- **使用者介面狀態**: 代表使用者介面狀態，包含當前篩選設定、頁面位置、載入狀態等
